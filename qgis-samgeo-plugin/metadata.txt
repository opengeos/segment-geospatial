about=A QGIS plugin for remote sensing image segmentation powered by Meta's Segment Anything Model (SAM).
    Features include:
    - Text-based segmentation (describe what you want to segment)
    - Interactive point prompts (click to segment objects)
    - Box prompts (draw rectangles to segment regions)
    - Save results as vector layers or GeoTIFF rasters
    - Support for GeoTIFF and common image formats

changelog=
    1.6.0 - Model weights, mask attributes, tiled segmentation and fixes
        - Includes all 1.5.0 changes below (1.5.0 was not published)
        - Clicks, boxes and batch points use the raster's geotransform, so
          rotated or sheared rasters map to the right pixels
        - Python 3.8 compatibility for older QGIS 3.22 builds
        - Fix QGIS crashing with "OMP: Error #15" when loading a model on
          macOS and Windows (conda-forge QGIS ships its own OpenMP runtime)
        - Vector output works with rasterio < 1.5 (QGIS builds with an older
          Python); the plugin now installs segment-geospatial >= 1.6.0 and
          asks existing setups to update their dependencies
    1.5.0 - Model weights, mask attributes and tiled segmentation
        - Choose model weights per family: vit_h/vit_l/vit_b for SAM 1,
          hiera tiny/small/base-plus/large for SAM 2, sam3 or sam3.1 for SAM 3
        - Saved vector masks carry "source" (image file name) and "prompt"
          (text, point, box or batch_point) attributes
        - Save dialogs default to the source image's folder, with an option
          to save there automatically
        - Tiled mode for text prompts on large images, with tile size,
          overlap and processing scale settings
    1.4.2 - Confidence scores in vector output
        - Saved vector masks carry a per-feature "score" attribute with the
          model's confidence (requires segment-geospatial >= 1.4.2)
        - Fix plugin reload cleanup
    1.4.1 - Dependency installer fix
        - Fix macOS QGIS installer dependency installation
    1.4.0 - Qt5/Qt6 dual compatibility for QGIS 4.0 (qualify enums, replace exec_())
    1.3.0 - Add one-click installation of dependencies
    1.1.0 - Fix plugin name import
    1.0.0 - Initial release
